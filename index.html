How this works: each guest gets their own personalised card link (with their name baked in) to send via WhatsApp, email, or text. The QR code on their card is only for door staff — it encodes that guest's ID + party size so scanner.html can check them in with a camera, no internet lookup needed.

Getting this live in front of guests

  1. Download this folder (index.html, invite.html, scanner.html, manifest.json, sw.js).
  2. Deploy it as a static site — drag-and-drop the folder onto Netlify Drop, or push it to a GitHub repo and enable GitHub Pages, or use Vercel. All are free and give you an HTTPS URL, which is required for camera access.
  3. Once live, come back to the Guests tab, click Copy invite link for each guest, and send it to them individually.
  4. On the wedding day, open yourdomain.com/scanner.html on the phone(s) at the entrance, tap "Start camera," and scan each guest's QR as they arrive. It works fully offline once loaded — no server needed.
  5. Optional: on that scanning phone, tap "Add to Home Screen" from the browser menu — it'll open full-screen like a native app (that's the PWA part).
Note on data: guest data lives in this browser's local storage on your device, and each guest's QR is self-contained (their info is encoded directly in the code). There's no shared cloud database — this keeps it free and simple, but means check-ins are tracked per scanning device rather than synced live across multiple entrance phones.
Built for a wedding, not a corporation — no accounts, no ads, no tracking.
